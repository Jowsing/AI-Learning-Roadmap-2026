# 高等代数 16 周学习计划

> 面向 AI、机器学习与工程实践，建立“概念理解 → 手算推导 → Python 验证 → 场景应用”的完整学习闭环。

## 学习目标

完成本计划后，应能够：

- 熟练进行矩阵运算、线性方程组求解与初等变换
- 理解向量空间、线性相关、基、维数和坐标的本质
- 使用线性映射与矩阵刻画空间之间的关系
- 掌握特征值、特征向量、对角化和相似变换
- 理解内积、正交投影、最小二乘和 QR 分解
- 掌握行列式、二次型、正定矩阵和谱定理
- 理解 SVD、PCA 等机器学习方法背后的线性代数原理
- 使用 NumPy 实现并验证主要算法，识别数值计算中的稳定性问题

## 执行方式

- **周期：** 16 周
- **投入：** 每周 6–8 小时
- **比例：** 40% 概念与推导、30% 习题、30% 编程实验
- **每周输出：** 1 份笔记、10–15 道习题、1 个 NumPy 实验
- **工具：** Python、NumPy、Matplotlib、Jupyter Notebook

状态说明：`⬜ 未开始` · `🟨 进行中` · `✅ 已完成`

## 推荐资源

- MIT 18.06 Linear Algebra：配合 Strang 教材学习
